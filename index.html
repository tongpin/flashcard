📖 របៀបប្រើប្រាស់ប្រព័ន្ធស្វ័យសិក្សា (User Guide)

មគ្គុទេសក៍ងាយៗសម្រាប់សិស្សានុសិស្សថ្នាក់ទី១២ ត្រៀមប្រឡងបាក់ឌុប

🎯 គោលបំណង៖ ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងដើម្បីជួយលោកអ្នករំលឹកមេរៀនជីវវិទ្យា តាមរយៈសំណួរ-ចម្លើយប្រឡងបាក់ឌុបទាំង ៦៣ និងឯកសារ PDF ដើមយ៉ាងមានប្រសិទ្ធភាព។

1. 🎴 ការប្រើប្រាស់ Flashcards 3D

  • ចុចលើប័ណ្ណសំណួរដើម្បីបម្លែងមើលចម្លើយ (Flip Card)។
  • ប្រើប្រាស់ប៊ូតុងសញ្ញា (← / ទ) ឬចុចលើ Keyboard របស់អ្នកដើម្បីផ្លាស់ប្តូរសំណួរ។
  • ចុចប៊ូតុង [✓] នៅពេលអ្នកបានឆ្លើយចេះចាំ ដើម្បីកត់ត្រាវឌ្ឍនភាពរបស់អ្នក។
  • ចុចប៊ូតុង [▶] ដើម្បីបើកដំណើរការលេងស្វ័យប្រវត្តិ (Autoplay)។

2. 🎡 វិលកង់ចៃដន្យ (Spin Wheel)

  • ចូលទៅកាន់ទំព័រ វិលកង់ចៃដន្យ ហើយចុចប៊ូតុងវិលកង់ដើម្បីចាប់យកសំណួរដោយចៃដន្យសម្រាប់ធ្វើតេស្តខ្លួនឯង។

3. 📄 ការអានឯកសារ PDF ដើម

  • ចូលទៅកាន់ទំព័រ មើល PDF ដើម ដើម្បីអានឯកសារយោង និងលំហាត់ដើមដោយផ្ទាល់ក្នុងប្រព័ន្ធដោយមិនបាច់ទាញយក។

4. 🚩 ការរាយការណ៍បញ្ហា

  • ប្រសិនបើអ្នកជួបកំហុស (Typo) ក្នុងសំណួរ/ចម្លើយ អ្នកអាចចុច រាយការណ៍បញ្ហា នៅ menu ខាងឆ្វេង ដើម្បីផ្ញើសារជូនរដ្ឋបាលតាម Telegram ភ្លាមៗ។

🔒 គោលការណ៍ភាពឯកជន (Privacy Policy)

បច្ចុប្បន្នភាពចុងក្រោយ៖ ខែសីហា ឆ្នាំ២០២៦

🛡️ សេចក្តីសង្ខេបអំពីភាពឯកជន៖ ប្រព័ន្ធស្វ័យសិក្សាជីវវិទ្យា ២០២៦ ត្រូវបានរចនាឡើងដោយគោរពតាមសិទ្ធិភាពឯកជនរបស់សិស្សានុសិស្ស ១០០%។ យើងមិនប្រមូល មិនត្រួតពិនិត្យ និងមិនបញ្ជូនព័ត៌មានផ្ទាល់ខ្លួនរបស់អ្នកទៅកាន់ Server ខាងក្រៅណាមួយឡើយ។

1. ការរក្សាទុកទិន្នន័យលើឧបករណ៍របស់អ្នក (Local Storage)

រាល់ព័ត៌មានដូចជា៖ ឈ្មោះសិស្ស, វឌ្ឍនភាពនៃការឆ្លើយសំណួរ (សំណួរដែលបានឆ្លើយរួច), និងទំព័រចុងក្រោយដែលអ្នកបានមើល ត្រូវបានរក្សាទុកតែនៅក្នុង LocalStorage នៃ Browser លើទូរស័ព្ទ ឬកុំព្យូទ័ររបស់អ្នកប៉ុណ្ណោះ។

2. គ្មានការប្រមូលទិន្នន័យផ្ទាល់ខ្លួន (No External Data Collection)

យើងមិនប្រមូលអាសយដ្ឋាន IP, លេខទូរស័ព្ទ, Email, ឬព័ត៌មានសម្គាល់ខ្លួនណាមួយឡើយ។ ប្រព័ន្ធនេះដំណើរការដោយផ្ទាល់នៅលើ Client-side Browser របស់អ្នក។

3. សិទ្ធិ និងការគ្រប់គ្រងទិន្នន័យរបស់អ្នក

  • អ្នកអាចកែប្រែឈ្មោះរបស់អ្នកបានគ្រប់ពេលតាមរយៈប្រអប់បញ្ចូលឈ្មោះខាងលើ។
  • អ្នកអាចលុបទិន្នន័យ និងកំណត់វឌ្ឍនភាពសិក្សាឡើងវិញបានគ្រប់ពេល ដោយចុចប៊ូតុង "កំណត់ឡើងវិញ" នៅក្នុង menu ខាងឆ្វេង។

4. ការភ្ជាប់ទៅកាន់ឯកសារ PDF

ការមើលឯកសារ PDF ដើមនៅក្នុងកម្មវិធីនេះ គឺធ្វើឡើងដើម្បីសម្រួលដល់ការសិក្សាស្រាវជ្រាវរបស់សិស្សថ្នាក់ទី១២ ត្រៀមប្រឡងបាក់ឌុបតែប៉ុណ្ណោះ។
